# Round 8: one new pre-registered test per species

Three specialist reviews (orca false alarms, blue/fin low frequencies, humpback and crowd labels) and one adversarial
review. Chosen: 8a orca with a stricter counting rule on new blocks only (the rule was picked after seeing 7e, so it is
never reported as a 7e result); 8b humpback, a powered second listening round with weights back to the pool and a
test-retest kappa; 8c blue/fin call index from 6 h/day (MBARI's own values peak in November on the judged days, so the
Oct-Dec mark was fair); 8.0 Pi equivalence. One primary test per species; marks unchanged; the page counts all tests.
