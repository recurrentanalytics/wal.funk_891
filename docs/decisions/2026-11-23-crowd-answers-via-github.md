# Game answers are collected via GitHub for now

**Decision (owner):** "Send" opens a prefilled GitHub issue; a GitHub Action validates and stores it. Supabase (answers
without an account, live counts) is prepared but needs an account the owner creates. **Privacy:** on the GitHub route
the sender's GitHub name is public on the issue; the page says so before sending and the ingest does not store it.
