    What the words mean
    Window
    A 5-second slice of audio. The model judges one window at a time. Windows overlap by half, so a call is never cut in two.
    Spectrogram
    A picture of sound: time left to right, pitch bottom to top, loudness as brightness. Whale calls show up as bright streaks.
    Embedding
    The 1,536 numbers Perch makes from a window. Windows that sound alike get similar numbers, even for animals Perch never heard in training.
    Classifier
    A small model trained on labelled examples that turns an embedding into one orca score from 0 to 1.
    Threshold
    The score at which a window counts as a call. Fixed at 0.5 before testing, never moved to make a test pass.
    Balanced accuracy
    The average of two hit rates: calls correctly found, and quiet windows correctly left alone. 0.5 is guessing, 1.0 is perfect. Plain accuracy would reward a model that never says "call", because most windows are quiet.
    Gate
    A pass mark set before a step runs. If a step misses it, work stops until the owner decides.
    Throttling
    The Pi slowing itself down when it gets too hot (from 85 °C). It protects the chip but makes everything slower.
    Candidate
    A detection that looks unusual. It only becomes a finding after a person has listened to it and compared it with what MBARI and Orcasound already report.
